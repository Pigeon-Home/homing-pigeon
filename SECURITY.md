# Security policy

Report a vulnerability privately. Do not open a public issue for it.

Use GitHub private vulnerability reporting on this repository, or email the address in the repository profile.

Please include:

- what is affected (agent, Oracle, a specific extension, an install path)
- how to reproduce it
- the impact you expect

Signed jobs, the mailbox secret, and the Oracle loopback are the sensitive surfaces. A report that needs a secret to exploit is still welcome.
