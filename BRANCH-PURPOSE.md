# The purpose of this branch

This branch is an intermediate step, cut from main exactly as main stood.

Its job comes after the documentation corrections are finished: a research
pass over every statement in the project's markdown documents, sorting each
statement into one of two kinds — a statement about the project before its
first release, or a statement about the project after it. The first release
is 4.0, and that release is the line the sorting is measured against.

Nothing here changes main. This branch is a place to do that sorting work
carefully, in the open, one document at a time.
