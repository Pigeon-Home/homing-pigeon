# draft-homing-pigeon-00

Homing Pigeon Message Protocol, Version 1

Superseded. This revision specified version 1 of the Homing Pigeon message protocol. It is superseded by [draft-homing-pigeon](draft-homing-pigeon.md), the canonical document, which specifies versions 1 and 2 in a single document: Part I carries the version 1 specification forward and Part II adds the version 2 DTLS session binding.

This stub remains so that references to draft-homing-pigeon-00 continue to resolve. It carries no normative content.
