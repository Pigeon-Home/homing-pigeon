# Stage 9 — P1 at 500,000 characters

This is the record of the gate property family checked at
a script bound of 500,000 characters: P1(500000), the nine
clauses of `properties.md` for every handling whose script
has at most 500,000 characters. The stage was defined and
not run. This is its own run.

The character count is not a state variable, and no step
of `Next` branches on a script's length or its text. The
argument is the one `stage6-cap.md` gives, and this stage
does not replace it. What this stage adds is the run at
the 500,000 bound.

## How the bound was set for this run

A scratch copy of `Gate.tla` declares P1(500000) in its
header, and its `GateEnforce.cfg` comment names that
bound. Diffed against the tree copy, the difference is
that header and that one comment. No action, invariant,
or message field differs. The tree copy stays at the
production-cap declaration, which subsumes this rung.
`Claim.tla` is unchanged.

## What was checked

TLC 2.19, each run exhaustive, on Java 17. Every run
starts from 786,432 initial states, and the depth of each
gate search is 18.

The counts match the earlier rungs exactly. `P1Inv`
holding over that set is, at this rung, P1(500000).

## The two counterexamples that are supposed to exist

`GateWitness.cfg` fails as it should: a good job still
executes. 3,095,425 generated, 2,308,999 distinct.

`GateDefaultWitness.cfg` fails as it should: with the
audience feature off, a job still executes with
`audienceOk = FALSE`. 3,106,561 generated, 2,320,141
distinct. Under enforce, clause 4 holds.

## The conformance family after the check

The constraints module, the conformance module, and the
companions through `test_proof_conformance_p6.py` run
253 tests, all passing. `test_skip_registry.py` runs 5,
all passing. No runner behaviour changed, and no model
file on `main` changed.

## What this does not say

P1(500000) holding says nothing new about the cap rung.
A script of half a million characters is inside the
code's byte cap, and this check does not move that cap.
The content-independence series is a different artefact.
