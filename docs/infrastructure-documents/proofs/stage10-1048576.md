# Stage 10 — P1 at 1,048,576 characters

This is the record of the gate property family checked at
the last rung: P1(1048576), the nine clauses of
`properties.md` for every handling whose script has at
most 1048576 characters. That number is the production
script cap's own number. A character is at least one
UTF-8 byte, so every script the runner can accept has a
character count of at most 1048576. The two measures stay
different measures: characters in the model, bytes in
the code.

The stage was defined and not run as this stage. The cap
rung was re-run during stage 6 and recorded in
`stage6-cap.md`. This is the ladder's own run at the
bound, under this stage's name.

names P1(1048576). Diffed against the tree, the

## What this does not say

This is the top of the character ladder. It does not
claim a script the byte cap refuses. The
content-independence series, whose record of the same
number is `stage10.md`, is the scripts presented to the
real gate. This record is the model. The unbounded-length
step remains available and is still not wanted: an
unbounded length would be a claim about scripts the byte
cap refuses.
