What “asymptotic” means, plainly

An asymptote is a line a curve gets closer and closer to, without reaching it.

Picture filling a bucket with a hose that weakens as the bucket fills. Early on the level shoots up. Later it creeps. The rim is the asymptote — the level approaches it, but the rise keeps shrinking.

Applied here: if there is a practical limit — every token there is to find in the tree, say — growth would not stop with a sudden flat line. It would ease into that limit, exactly like the green curve above.
