## Scope

Design level only at this stage, per the conductor's plan
for the item:

A. Define a secret agent prompt as a signed job request,
   never carrying credential material.
B. Publish a small catalog of approved prompt patterns
   with their key policy and result view.
C. Write the refusal list in: no prompt may ask any agent
   to fetch or reveal a secret.
D. Route catalog prompts through Oracle review, flagged
   ones through the human approval gate.
E. Provisioning stays outside prompts, secrets placed by
   hand as the rotation doc prescribes.
F. Test injection shaped prompts against the catalog,
   refusal required, canary strings watching.
G. Document the catalog in the reader guides, desk review
   before any pattern ships.

## Where critical security news goes

The project keeps an account on X under the Pigeon Home
name, and that account has mainly one job. If a critical
security issue ever arrives in this software, the notice
goes out there, publicized and published where everyone
running the software can see it. Anyone who wants the
word first on something that serious should watch that
account.
