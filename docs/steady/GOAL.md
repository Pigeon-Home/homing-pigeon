# The goal

Read this page first. It is the owner's page. It says what
the project is for and what done means. It was written on
2026-11-19 at the owner's word, from the tree as it stood,
and it stands until he changes it. Only he changes it.

## The goal

A person runs Homing Pigeon on a machine of their own. A
cloud AI does work there through signed messages. The
security of that is by default, can be checked by the
person, and is proven by the project.

## Done means

1. **The runner.** An official release, secure by default
   on Linux, macOS, FreeBSD and Windows, with the open
   lines of the release plan closed.
2. **The protocol.** Versions 1, 2 and 3 stand as posted
   Internet-Drafts, and version 4 states the security
   model.
3. **The proof.** Every constraint of version 4 has a
   property, a checked model and a suite on the running
   code, with the fuzz data beside it. What is assumed is
   said.

## Not a goal by itself

The count of commits, releases, questions or tokens. They
measure the work that stands behind a release. They do not
measure the distance left.
