The `de_dust_corpus.py` gain is small in lines and the largest in
what it proves. The corpus replay shows the runner meets every
oracle's contract, so before this no test had seen an oracle fire.
`test_de_dust_oracles_bite.py` runs the version 2, query and board
mail oracles on a seed each accepts, with the handler wrapped to run
for real and then break one promise, and each oracle ends in a Crash
of the right kind.

## Found on the way

- `ci_run_report.py`: an origin remote that is not on GitHub was split
  on a host it does not contain, so the whole URL came back as the
  repository name. It now falls through to the message that names the
  variable to set.
- `de_dust_survivors.py`: two of its ten mutation operators, `and` to
  `or` and the boolean flip, had never run, and its `_Mutator` class
  is unused (every mutant is built through `sites`, `apply` and
  `_replace`).
- A commit on main carried three merge conflict blocks in
  `runner/cloud/send_job.py` until the next commit removed them.
  `test_no_conflict_markers.py` now fails any tracked file that
  carries one.
