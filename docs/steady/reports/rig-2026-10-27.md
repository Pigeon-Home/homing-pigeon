2026-10-27. A Hetzner Cloud virtual machine in Nuremberg
(nbg1): KVM, 1 vCPU (AMD EPYC-Genoa, 1 thread), 917 MiB memory,
19 GB disk, Fedora Linux 44 x86_64, Python 3.14.7. Operated by
Muse, it carries the campaign's grow work (the tree is main,
fetched at the start of every grow) and the hosted runner
(homing-pigeon.service, hosted profile, poll 20 s, outbound
only) polling the Cloudflare queue. No address, password or
account name is recorded in the file.
